## Mission

**PaaS2** is a self-hosted PaaS built for teams who want to ship product, not wrestle Kubernetes.

The **Obsidian Flux** visual system — void backgrounds, purple-to-cyan gradients, glass cards, and technical type — reflects a “Futuristic Utility” personality: CLI precision with premium SaaS polish.

## What is different?

- **Developer-first** — CLI and GitOps by default
- **AI in operations** — monitor, diagnose, and self-heal
- **Open architecture** — loosely coupled services behind a central API
- **Self-hosted** — full control of data and infrastructure
