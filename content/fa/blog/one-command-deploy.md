با PaaS2 می‌توانید از هر دو مسیر استفاده کنید:

1. **Git push** به ریموت پلتفرم
2. **CLI** برای ساخت، مقیاس و لاگ

هر دو مسیر به همان API Server می‌رسند. موتور هوش مصنوعی پس از رول‌اوت، سلامت را بررسی می‌کند و در صورت نیاز پیشنهاد رفع می‌دهد.

```bash
git push paas2 main
paas2 apps logs my-app --follow
```
