## پایه

تمام پنل‌ها و CLI از طریق **API Server** (Go + Gin) با پلتفرم صحبت می‌کنند. احراز هویت با Keycloak (OIDC) انجام می‌شود.

## مستندات تعاملی

Swagger زنده را اینجا ببینید:

[Swagger API](https://api.devmad.ir/swagger/index.html)

## مفاهیم اصلی

- **Apps** — چرخه عمر اپلیکیشن و استقرار
- **Environments** — staging / production
- **Secrets** — متغیرهای محرمانه
- **Billing** — سهمیه و صورتحساب
- **Tickets** — پشتیبانی

برای جزئیات schema و نمونه درخواست‌ها از Swagger استفاده کنید.
